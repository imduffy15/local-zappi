## Offline-operation finding

Independent offline control remains unimplemented. `server.py` reports `offline_control_supported: false` and rejects mode requests when forwarding is disabled. `Control.ready()` requires a recent verified upstream reply. The runtime does not instantiate `SessionNegotiator`; only tests and the firmware emulator exercise it.

Removing the offline limitation would therefore misdescribe the software. The [architecture document](architecture.md) describes the present shared session and the work needed for independent charger-facing and cloud-facing sessions.
